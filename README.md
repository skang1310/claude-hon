# 클로드혼 — 다 굴려 먹자

버그 한 마리에서 시작해 SaaS, 엔터프라이즈, 빅테크까지 전부 굴려 먹는 3D 웹 게임.

플레이: https://skang1310.github.io/claude-hon/

- `index.html`, `game.js` — 게임 본체 (Three.js, 빌드 과정 없음)
- `logos.js` — [Simple Icons](https://simpleicons.org)(CC0)에서 가져온 브랜드 로고 path (`tools/fetch-logos.py`로 재생성)
- `toy-3d.html`, `classic-2d.html` — 이전 버전

팬메이드 패러디입니다. 등장하는 회사명과 로고는 각 소유자의 상표이며, Anthropic을 포함한 어떤 회사와도 제휴·후원 관계가 없습니다.
